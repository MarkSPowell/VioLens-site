See inside your HTTP and HTTPS traffic.

VioLens is a debugging proxy for Windows and Mac. It shows you every request your browsers and apps make, and lets you change them and send them again. If you've used Fiddler Classic, you'll know your way around. It's free, for any use.

Download Read the User Guide View on GitHub

It's a preview. It runs on 64-bit Windows 10 and 11, and on Apple silicon Macs with macOS 11 or later.

Capturing a page load, reading the request and response headers, and the Timing tab's DNS, connection, TLS and wait breakdown.

What it does

Point a browser, an app or a phone at VioLens and every request shows up in the list, already decrypted and decompressed.

Captures HTTPS and HTTP

HTTPS is decrypted with a root certificate created on your own machine. VioLens sets itself as the system proxy while it runs and puts your settings back when you stop it.

Shows you what was sent

Headers, Raw, JSON, WebForms, images, Hex and Cookies views, plus every WebSocket message. gzip, deflate, Brotli and zstd bodies are decompressed for you.

Breakpoints and AutoResponder

Pause a request or response, edit it and let it carry on. Or answer requests yourself with a file, a redirect, a delay or an error, so they never reach the server.

Composer and Replay

Write a request from scratch or start from a captured one, and send it byte for byte, binary bodies included. Press R to send the selected request again.

Timing

A waterfall of each request's phases, a Timing tab for the details, and Statistics showing bytes, compression savings and the slowest requests.

Find, Compare and TextWizard

Search inside bodies, put two sessions side by side, and decode Base64, URL encoding, JWTs and more.

QuickExec, scripts and extensions

Type commands like ?login or bpu /api. Load a CustomRules.js-style script to change traffic on the way through, or add .NET extensions.

Works on a company network

It goes through your corporate proxy, PAC scripts and sign-in included, and tells you when a server asks for a client certificate. It can capture phones too, and it opens and saves SAZ and HAR files.

Coming from Fiddler Classic?

I've used Fiddler for over 15 years, so VioLens works the way I expect a debugging proxy to work. It also picks up a few things the web has gained since Fiddler Classic's last big update.

What carries over

  • Your .saz files open as they are, and VioLens saves them too.
  • FiddlerScript: OnBeforeRequest, OnBeforeResponse, Rules menu options, context actions and columns.
  • Extensions can be ported from their source with few changes. Three ported ones come with the installers.
  • Breakpoints, AutoResponder rules, Composer, Replay, Find, TextWizard and the QuickExec box.

What's new

  • Timing laid out the way the browser developer tools show it.
  • Compare is built in, so there's no separate diff program to install.
  • Live WebSocket messages, with compressed and fragmented ones put back together.
  • HAR import and export, zstd and Brotli, and cookie warnings based on today's browser rules.
  • It runs on a Mac as well as Windows (it's built on .NET 10 and Avalonia).

Building your own tool?

The proxy engine is a separate .NET library, Violens.ProxyCore, published on NuGet with each release. You can build your own debugger, capture tool or test harness on it, with Fiddler-style hooks such as OnBeforeRequest, AutoTamper, session flags and breakpoints. If your app is still on .NET Framework, Violens.ProxyHost.Client runs the engine in a small process of its own and talks to it for you.
